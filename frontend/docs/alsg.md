# Adaptive Life State Graph (ALSG)

## Purpose

ALSG models relationships between different aspects of a user's life.

Instead of storing isolated values, ECHO stores connected life states.

Every node can influence multiple other nodes.

The graph evolves as the AI learns the user's behavior.
